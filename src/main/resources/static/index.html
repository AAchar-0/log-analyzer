Concurrent Log Analyzer

Reads web-server logs and reports errors, busy minutes, slow routes and response-time percentiles. Run it one thread at a time, in parallel, or with Java 21 virtual threads, and compare the speed.

Demo project. The sample logs are synthetic (made up by the program) and contain no real people. Please do not upload logs that contain real IP addresses or other personal data. Uploaded files are used only to make the report and are deleted straight away.

Log format

One request per line: the common web-server format plus the response time at the end.

192.0.2.7 - - [01/Nov/2026:10:15:32 +0000] "GET /api/products/42 HTTP/1.1" 200 1532 18
client    - user [time]                    "request"                       status bytes ms

Login attempts are POST requests to a route ending in /login or /signin. The client address is used only to find the country and nearest city of those attempts; it is never stored. Logins from the areas you list above are treated as malicious.

Lines that do not match are counted as malformed and skipped. Numbers inside paths are grouped as {id}, so /api/products/17 and /api/products/18 count as one route.
